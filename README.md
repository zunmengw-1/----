# 沪深主板分钟级量价因子研究

本项目研究沪深主板 A 股的五分钟收益预测。在每个符合筛选条件的分钟收盘后，模型读取同一股票最近 30 根完整分钟线，为下一分钟开盘到第五分钟收盘的对数收益率打分。

## 2026-11-28 进阶版

上一版用 20 通道输入比较共享 TCN 和逐股微调，在 49 个开发日评估排序与成本。本版把下一分钟开盘到第五分钟收盘的收益固定为训练标签，改用六列基础量价和逐分钟时钟，并在相同的训练预算下检验 TCN 相对简单模型的增益。两版的训练期、验证日期和指标分组均有变化，跨版本数字不宜直接计算提升幅度。

[上一版提交](https://github.com/zunmengw-1/----/commit/2878cc27b4c2052d93e427f01985ea3c77dcdaf5) · [上一版研究方法和结果](docs/method.md)

- **数据与样本。** 已实现 Qlib 分钟行情和股票日元数据读取、交易时段对齐、停牌与限价筛选，以及按股票日构建训练缓存。输入窗口在午休和跨日处重新累计。未来入场或退出行情缺失时，候选保留，单独标记标签可用性。
- **特征与模型。** 开高低收、成交量和成交额先在窗口内归一化，再用训练集估计的位置均值和分时价格倍率处理。当前默认是 16 个隐藏通道的 TCN，在第一个残差块之后用每根分钟线的上下午标记和时段进度对通道加权。预测头接入时钟、八通道输入和纯量价模式均可用于对照。
- **训练与评价。** 训练使用按预测分钟缩放的目标，检查点保存恢复原始收益率所需的尺度。训练入口支持短试跑、5,000 批试验和全量一轮训练。预测导出保留股票、预测时间、预测值和可空标签。

### 同一窗口与训练预算下的验证结果

训练期为 2023–2024 年。三种拟合模型使用相同顺序的 5,000 个训练批次，共 9,759,378 个窗口。以下为已检查过的 2025 年上半年 67 个验证日，合计 33,362,162 个候选、32,834,005 个有效标签。2025 年下半年留作最终测试。

| 模型 | 截面 Rank IC | 日内时序 Rank IC | 验证 Huber（统一尺度） | 每分钟前 1% 信号的平均毛收益 |
| --- | ---: | ---: | ---: | ---: |
| 五分钟反转 | 0.05998 | 0.05717 | 仅排序 | 3.67 bp |
| 全窗口线性回归 | 0.06481 | 0.07350 | 0.297522 | 4.07 bp |
| 全窗口单隐层 MLP | 0.07890 | 0.07508 | 0.296090 | 4.44 bp |
| 时钟加权 TCN | 0.07633 | 0.07211 | 0.296039 | 4.29 bp |

截面 Rank IC 衡量同一分钟给不同股票排序的能力。MLP 在 67 天中有 42 天领先 TCN。TCN 的验证 Huber 最低，恒预测零的 Huber 为 0.297149。表中毛收益按入选信号逐笔等额计算。按假设的 10 bp 往返成本，TCN 平均每笔为 −5.71 bp。账户级表现仍需结合实际成交、底仓和可卖数量单独检验。

### 运行与核验

在仓库根目录、装有项目依赖及 pytest 和 Ruff 的 Python 3.12 环境中运行以下命令。训练默认读取上级目录的 `data/qlib_cn_1min`、本地 `data/stock_day_cache/train` 和 `data/training_metadata/metadata.json`。可用 `--qlib`、`--cache` 和 `--metadata` 指定其他位置。

```sh
python -m pytest -q
ruff check src/__init__.py src/data src/features src/models tests scripts
python scripts/train_tcn.py --smoke --output "$(mktemp -d)/run"
```

本次提交前运行了全部 142 项测试，并对本版源码、训练入口和测试运行了 Ruff，均通过。短试跑入口运行 100 个训练批次，产出 `model.pt` 和 `report.json`。数据范围、标签定义、样本筛选与验证方法见[项目规范](AGENTS.md)。

上一版的 `intraday-tcn` 命令继续用于共享模型与逐股微调的历史流程，见[上一版运行说明](docs/workflow.md)。
